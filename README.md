# Метрика

Интерактивный учебный стенд на русском языке: «Погрешности измерений и их классификация. Средства измерений и их свойства».

## Возможности

- Четыре основания классификации погрешностей с формулами, примерами и наглядными схемами.
- **Лаборатория**: мишень истинного значения (систематическая, случайная, грубая погрешность с расчётом θ и σ) и гистограмма разброса с кривой нормального распределения.
- Пять видов средств измерений (мера, преобразователь, прибор, установка, система) со схемами прохождения величины.
- Виртуальные штангенциркуль, линейка, микрометр и вольтметр с подвижной шкалой и паспортом прибора.
- Тренажёр отсчёта по вольтметру: допуск половина цены деления и счётчик верных ответов.
- Шесть метрологических характеристик прибора.
- Практикум: расчёт абсолютной и относительной погрешностей, обработка серии измерений, расчёт по классу точности и подбор класса по приведённой погрешности.
- Тест из одиннадцати вопросов с объяснением каждого ответа.
- Сохранение изученных разделов и результата теста в localStorage.
- Мобильная версия, управление с клавиатуры и поддержка уменьшенной анимации.

## Запуск

```bash
npm ci
npm run dev
```

Сборка и проверка типов:

```bash
npm run build      # tsc --noEmit + vite build -> dist/
npm run preview    # локальный просмотр собранного dist/
npm run test       # браузерные проверки Playwright (нужен npx playwright install chromium)
```

## Публикация

Деплой автоматический: пуш в `main` запускает workflow `.github/workflows/deploy.yml`, который собирает проект и выкладывает его в GitHub Pages.

Адрес сайта: https://dedomorozoff.github.io/measurement-stand/

Если это первый запуск, в репозитории включи **Settings → Pages → Source: GitHub Actions** — один раз, дальше деплоит workflow.

## Файлы

- `src/App.tsx`: оболочка, навигация, страницы разделов и сохранение прогресса.
- `src/data.ts`: учебные материалы, приборы, формулы и вопросы теста.
- `src/components/TargetExperiment.tsx`: интерактивная мишень для погрешностей.
- `src/components/GaussExperiment.tsx`: гистограмма отклонений на canvas с кривой PDF.
- `src/components/InstrumentVisual.tsx`: SVG-модели приборов.
- `src/components/GaugeTrainer.tsx`: тренажёр снятия показания.
- `src/components/Practice.tsx`: практикум и мини-эксперимент.
- `src/components/Quiz.tsx`: тест и разбор ответов.
- `src/utils/`: числовые функции, работа с клавиатурой, склонения.
- `src/index.css`: оформление и адаптивность.
- `tests/stand.spec.ts`: браузерные проверки.

## Учебные допущения

Характеристики виртуальных приборов условные. Для реальных измерений используйте паспорт конкретного прибора. В расчёте по классу точности рассматривается класс в виде простой цифры, шкала от нуля и нормирующее значение, равное верхнему пределу. Стандартная ошибка среднего не заменяет полную оценку погрешности или доверительный интервал.
